# Sheet Workbench

## 새 실험 기능: 기존 엑셀로 업무 이어하기

기존 파일 작업대는 유지하고, `업무 이어하기` (`?mode=work`)를 별도로 추가했습니다. 기존 엑셀과 이번 근거 자료를 대조하고, 기간·규칙·변경안을 사람이 확인한 다음 복사본을 만드는 기능입니다. 공개 사이트가 PC 파일에 접속하지는 않습니다. 선택형 Windows 연결 프로그램은 [PC 설치·지원 범위 안내](docs/COMPANION.md)를 확인하세요.

모든 엑셀이나 급여 업무를 자동 처리하는 완성 서비스가 아닙니다. 계산에는 설치된 Excel이 필요하고 수식은 보호합니다. 매크로·외부 데이터 새로고침·AI가 생성한 코드는 실행하지 않습니다. 로컬 Ollama가 기본이며 모델이 없다고 클라우드로 몰래 전환하지 않습니다. 기존 브라우저 기능과 버전 1 레시피는 그대로 사용할 수 있습니다.

30초 한국어·영어 소개 영상은 검증된 기존 이어붙이기·검토·내보내기 흐름을 가상 자료로 보여줍니다. 복잡한 급여 자동화가 실무 검증을 마쳤다는 뜻은 아닙니다.

**스프레드시트 파일은 그대로 두고, 반복 작업은 확인 가능한 흐름으로 만드세요.**

Sheet Workbench는 CSV와 지원 범위의 XLSX 파일을 다루는 오픈소스 알파입니다. 현재 리뉴얼의 기본 경로는 파일 우선입니다. 파일을 열고, 시트나 CSV 범위를 확인하고, 변경 미리보기를 본 뒤에만 적용합니다. 기본 로컬 경로에는 가입·계정·데이터베이스가 필요하지 않습니다.

> **파일 작업 중심 알파 — 2026-09-09.** 이 소스에는 브라우저 로컬 리뉴얼이 포함되어 있습니다. [공개 작업 도구](https://duct-tape2.github.io/sheet-workbench/?lang=ko)에서 체험하고, 실제 반영된 버전은 [배포 기록](https://github.com/duct-tape2/sheet-workbench/actions/workflows/pages.yml)에서 확인하세요. Pages 배포 성공은 관리형 팀 서비스, 실제 Google 연결, 모든 Excel 파일의 호환성을 뜻하지 않습니다. 가상 샘플이나 민감정보를 지운 시험용 사본부터 사용하세요.

## 먼저 로컬 파일로 시작하세요

Node.js `22.12+`와 npm에서 로컬 서버를 실행합니다.

```sh
npm ci
npm run dev
```

<http://127.0.0.1:5173/>을 엽니다. 현재 기본은 개인 로컬 파일 작업 공간이며 `?mode=local`을 붙이면 그 선택을 명시할 수 있습니다.

1. **파일 열기**에서 `.csv` 또는 지원되는 `.xlsx` 파일을 고릅니다.
2. 원본을 받기 전에 제안된 시트·제목 행·범위와 CSV 인코딩·구분자를 확인합니다.
3. 작업을 고르고 미리보기와 경고를 확인한 뒤 결과가 맞을 때만 **변경 적용**을 누릅니다.
4. 결과 CSV 또는 새 XLSX를 내려받습니다. **원본 / 서식 파일**은 해당 원본에 대해 화면에서 제공될 때만 선택하세요.

이 로컬 흐름의 파일 처리는 브라우저 메모리에서 시작합니다. **이 기기에 보관**은 기본으로 꺼져 있습니다. 이를 켜고 저장하면 프로젝트가 이 브라우저·이 기기의 IndexedDB에 저장됩니다. 이것은 편의용 사본이지 백업이나 공유 작업 공간이 아닙니다. 브라우저 데이터를 지우거나 다른 브라우저·기기로 옮기거나 브라우저 저장소를 잃으면 사본도 사라질 수 있습니다.

자세한 순서는 [한국어 빠른 시작](docs/QUICKSTART.ko.md)과 [English quickstart](docs/QUICKSTART.md)를 보세요.

## 무료 로컬 작업 흐름

로컬 경로는 유료 요금제나 연결 서비스 없이도 완결되도록 설계하고 있습니다.

- 표 정리: 공백 정리, 빈 행 제거, 중복 제거, 찾기/바꾸기, 선택 열 형식 변환, 요약.
- **이어붙이기:** 현재 파일과 들어온 파일을 모두 열고, 현재 파일을 기준 원본으로 고른 뒤 각 열을 명시적으로 연결합니다. 원본 파일은 수정하지 않습니다.
- **비교:** 현재 파일과 기준/이전 파일을 고르고, 하나 이상의 ID·기준 열과 비교할 필드를 연결합니다. 빈 ID나 중복 ID가 있으면 추측하지 않고 검토를 막습니다.
- **참조 조회:** 같은 기준 열 연결로 참조 파일의 선택 필드를 새 결과 열에 가져옵니다. 일치하는 행이 없으면 그 결과 필드는 비어 있습니다.
- 확정한 선언형 작업만 레시피로 저장하고, 새 로컬 파일을 연 뒤 원본을 직접 연결하여 재실행 미리보기를 봅니다. 개별 셀 수정은 현재 결과에는 남지만 레시피에 포함하지 않습니다.

모든 작업은 적용 전에 미리보기로 확인합니다. 되돌리기/다시 실행과 원본 행 정보는 결과 검토를 돕지만, 전달 전에 출력 파일을 직접 확인하는 일을 대신하지는 않습니다.

현재 로컬 보호 한도는 선택한 원본 파일 합계 25MiB, 가져온 행 10,000개입니다. 모든 Excel 기능을 지원한다는 뜻이 아닙니다. 암호화·매크로 중심·구형·지원하지 않는 구조의 통합 문서는 거부될 수 있습니다. 수식과 보호된 셀은 잠긴 상태로 둡니다. 중요한 파일의 유일한 사본으로 이 알파를 사용하지 마세요.

## 모드와 경계

| 경로                    | 용도                         | 자료 경계                                                                   |
| ----------------------- | ---------------------------- | --------------------------------------------------------------------------- |
| 기본 또는 `?mode=local` | 현재 리뉴얼의 개인 파일 도구 | 로컬 브라우저 처리, 사용자가 고른 기기 저장만 선택 가능                     |
| `?mode=team`            | 기존 팀 작업 공간 화면       | 직접 설치한 서버와 PostgreSQL이 필요하며 Pages의 관리형 서비스가 아님       |
| `?mode=demo`            | 이전 정적 가상 데모          | 가상 행만 사용. 정적 빌드에서는 실제 파일·계정 정보·Google 승인을 받지 않음 |

공개 Pages에는 회사 파일, 자격 증명, 개인정보를 입력하지 마세요. Pages 빌드에는 Fastify API, PostgreSQL, 업로드, 계정, 실제 Google 연결이 제공되지 않습니다.

## 팀/직접 설치 알파

기존 팀 경로는 로컬 평가용으로 유지됩니다. 계정·작업 공간·가상 XLSX 업로드/수정/다운로드·리비전·보호된 내보내기·역할 제어 계약은 로컬에서 시험했습니다. 루프백 전용 가상 시험은 다음처럼 시작합니다.

```sh
npm run demo:team
```

`TEAM_TRIAL_READY` 뒤 <http://127.0.0.1:3002/?mode=team>을 열고 `samples/team.xlsx`로 시작하세요. 가상 시험 자료는 `.local/team-trial`에 남고 `Ctrl+C`로 종료합니다. 이는 운영 배포가 아니며 실제 Google 연결과 메일 발송은 꺼져 있습니다.

Compose와 서버 문서는 호스팅 준비 완료 주장이 아니라 직접 설치 평가용으로 유지합니다. 외부 공개 전 [셀프호스팅 요구 사항](docs/SELF_HOSTING.md), [백업·복원·삭제 한계](docs/BACKUP_RESTORE_DELETION.md), [출시 체크리스트](docs/LAUNCH_CHECKLIST.md)를 읽으세요. 실제 Google OAuth/Picker/쓰기, Docker·공개 HTTPS, 실제 메일 전달, 데스크톱 Excel 재열기, 여러 팀 파일럿은 아직 검증되지 않았습니다.

## 검사와 증거

```sh
npm run check
npm run test:e2e:local
npm run test:e2e:static-demo
```

리뉴얼에는 로컬 자동·브라우저 테스트 증거가 있습니다. 공개 시 CI가 검사를 다시 실행합니다. 소스 공개와 실제 Pages 배포 성공은 다르므로 위 배포 기록을 함께 확인하세요. [로컬 검증과 남은 한계](docs/LOCAL_VALIDATION.md)를 보세요.

## 앞으로의 일 — 현재 제품 약속 아님

관리형 팀 호스팅, 예약 실행, 조직 관리, 선택형 AI, PWA/데스크톱/모바일 앱, 유료 요금제는 모두 로드맵 후보일 뿐입니다. 무료 로컬 파일 흐름은 기간 제한 체험판이 아니며, 현재 가격이나 유료 앱은 없습니다.

`.env`, 데이터베이스 덤프, 업로드 통합 문서, 토큰, 실제 회사 자료를 커밋하지 마세요. 이 프로젝트는 회사 스프레드시트·운영 사이트 코드·비공개 미디어·Google 시트 ID를 복사하거나 의존하지 않습니다.
