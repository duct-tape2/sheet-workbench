# Landing film

The 30-second film is available in English and Korean, with separate 16:9
desktop and 4:5 mobile compositions. It is a muted, inline MP4 rather than a
step-driven animation. Reduced-motion and data-saving preferences show a
poster with an explicit play control.

## What is real

The product sequences were recorded in the public local-file workbench using
synthetic office requests. Two CSV files contain six existing and three new
requests with differently named columns. Four explicit mappings are reviewed,
three additions are applied, and the downloaded CSV is checked against the
exact expected nine records. Original input hashes remain unchanged.

The filmed work is file append, review and export. It does not establish
universal workbook compatibility, autonomous payroll, OCR or AI execution.

## Creative provenance

The desk still was generated specifically for this project with GPT Image,
then animated with Grok Imagine. It is not a customer photograph or testimonial.
Reference advertising informed pacing and framing; no reference film footage,
logos or music were reused. An original Blender paper-scene experiment was
not included in the published cut because it weakened the product story.

The product interface is genuine recorded footage, not generated UI. Editorial
cuts, reading holds and a slowed review segment are used; this is not a
real-time performance benchmark. Website variants intentionally contain no
audio stream.

## Verification

`apps/web/public/media/landing-demo-manifest.json` records output hashes,
dimensions, codec, decoded frame count and sampled decoded-frame checks.
Each variant is H.264, 30 fps, 900 frames and 30 seconds, below 6 MiB.
Encoding checks do not measure persuasiveness or user conversion.

`tests/landing-ad-video.test.ts` checks the shipped artifacts. The local
Playwright suite checks responsive controls, reduced-motion manual play,
pause and mobile source selection. Original source media and previous public
assets are retained privately outside the public source history.
