# Supported-file matrix

The default personal file workbench accepts CSV and supported XLSX selections. It runs in the browser without a team account. The matrix below describes the existing guarded XLSX adapter and the separate, unverified Google path; it is not a promise that every spreadsheet feature round-trips.

## Personal file workbench

- Import up to 10 sources, 25 MiB of original files combined, 10,000 selected data rows combined and 100 columns per table. These are safety limits, not a performance guarantee.
- CSV supports explicit encoding/delimiter selection and quoted fields/newlines. Values stay text initially, including leading-zero IDs. Invalid quotes stop import; ambiguous dates and lossy number conversions are not silently guessed.
- Preview cleanup, append, previous/current comparison, reference lookup and grouped summaries before applying. Duplicate or missing matching keys stop operations that cannot identify a unique row.
- Download a new CSV or plain XLSX results table. The new XLSX writes text cells (including numeric-looking values); it does not preserve numeric cell types or the original workbook layout. Formula-like CSV text is escaped for spreadsheet safety.
- A separate original-workbook export is available only when the guarded XLSX adapter can safely apply the result; unsupported structural changes fail closed. Formula cells remain read-only. The PC's original file is never overwritten.
- Saved recipes contain rules and expected source structure, not file contents. Explicitly choose each replacement source when rerunning. Different filenames and row counts are accepted; incompatible selected sheets/headers/columns stop replay.
- Work is in memory until the user explicitly saves it to this browser. Browser storage can be removed by the browser or device administrator; download important outputs and recipes separately.

## Existing team adapter

| Input or feature                                                                                | Status                          | Current behavior / evidence                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------------------------------------------------------------------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Normal OOXML `.xlsx`                                                                            | Supported in the tested adapter | Reads bounded sheet selections and exports only selected changed cells.                                                                                                                                                                                                                                                                                                                                                                                                         |
| `.xls` binary workbook                                                                          | Rejected                        | Import raises `UNSUPPORTED_XLS`; save as `.xlsx`.                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `.xlsm`, VBA, macro sheets, `.xlsb`                                                             | Rejected                        | Macro/binary content is rejected; no macro execution.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Encrypted/password-protected workbook                                                           | Rejected                        | Encrypted packages fail closed.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ZIP traversal, duplicate entries, oversized/expanding archives                                  | Rejected                        | Path, entry-count, archive-size, member-size, expansion, and compression-ratio guards apply.                                                                                                                                                                                                                                                                                                                                                                                    |
| External links, workbook connections, pivot tables/caches, model/slicer/timeline/query features | Rejected                        | These structures are outside the safe patching contract.                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Formula cells                                                                                   | Read-only                       | Formula cells are preserved and cannot be patched by the supported editor path.                                                                                                                                                                                                                                                                                                                                                                                                 |
| Selected text/number/boolean/date cells                                                         | Supported when valid            | Values pass canonical validation; date order is explicit and not guessed.                                                                                                                                                                                                                                                                                                                                                                                                       |
| New XLSX rows                                                                                   | Supported with constraints      | Appends only into a verified plain table area with safe date style and no occupied/merged cells.                                                                                                                                                                                                                                                                                                                                                                                |
| Google Sheets                                                                                   | Alpha / live path unverified    | Limited to `drive.file`, using `GOOGLE_PICKER_DEVELOPER_KEY`/`GOOGLE_APP_ID`. Metadata-ID DataFilter writes, same-snapshot row identities and guarded row creation have mock coverage. Column-only sources cannot be written until metadata is previewed and consented to; new external rows need re-consent. Google has no same-cell CAS; metadata-enablement races may need explicit marker review. Live OAuth, Picker, writes, concurrency and deployment remain unverified. |
| CSV                                                                                            | Personal mode only              | Browser-local import/export is supported as described above. The team upload endpoint still accepts only supported `.xlsx` files. |
| Legacy Excel, arbitrary cloud files                                                            | Not supported                   | Convert to a supported file first. |

Current server upload limits include a 25 MiB request limit. The XLSX adapter also enforces a 50 MiB archive limit, 100 MiB expanded-size limit, 25 MiB member limit, and 10,000-entry limit. These are implementation limits, not performance guarantees.

Before accepting a real workbook, use a redacted copy and test import, edit, export, and reopen in the target Excel version. Native Excel round-trip remains a release gate.
