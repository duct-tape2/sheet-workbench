# 20–30 second demo script

Use the local synthetic demo only. Do not imply that the demo connected to Google, a company sheet, or a hosted service.

**0–3s — orient.** Open `http://127.0.0.1:5173` and say: “This is Sheet Workbench. The sample workspace is synthetic, so nothing here touches a real source.”

**3–8s — same rows, different views.** Click Table, Calendar, Board, and Report. Say: “One confirmed set of rows becomes four useful working views.”

**8–14s — edit safely.** Change a sample status and show the local saved indicator. Say: “In demo mode, the edit stays in this browser; real workspaces require sign-in, a role, and storage consent.”

**14–20s — language and workflow.** Switch to Korean or choose another synthetic template. Say: “The same flow is available in English and Korean, with templates for common work.”

**20–27s — set expectations.** Open Setup Guide. Say: “Self-hosting uses PostgreSQL and an HTTPS same-origin proxy. Google OAuth, Picker, live writeback, Docker, and a three-team pilot are still release gates.”

**27–30s — close.** Say: “Start with the local demo, then read the backup and launch runbooks before real data.”
